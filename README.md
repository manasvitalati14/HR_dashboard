# HR Analytics Dashboard

## Project Overview

The HR Analytics Dashboard is an end-to-end data analytics project developed during my internship at **ADKRITY DIGITAL SOLUTIONS PVT LTD**. The project analyzes employee data to identify workforce trends, employee performance, salary insights, training effectiveness, and attrition patterns.

The project demonstrates the complete analytics workflow using MySQL, Python, Power BI, HTML, and CSS.


## Objectives

- Analyze employee demographics.
- Monitor employee attrition.
- Evaluate salary distribution.
- Compare department performance.
- Analyze overtime and work-life balance.
- Generate business insights for HR decision-making.

- Attrition remains relatively low.
- Experienced employees receive higher salaries.
- Training positively influences performance.
- Promotion opportunities improve employee retention.
- Overtime should be monitored to maintain work-life balance.
